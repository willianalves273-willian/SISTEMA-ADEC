Conexão com Firebase

Para sincronizar computadores e celulares, use um projeto Firebase da igreja, autenticação por e-mail/senha e regras de acesso restritas. Não use regras públicas.

Preencha os dados do projeto para ativar a sincronização.

Preparação do Firebase

  1. Acesse Firebase Console e crie um projeto.
  2. Adicione um aplicativo Web e copie a configuração para os campos acima.
  3. Em Authentication, habilite E-mail/senha e crie usuários apenas para pessoas autorizadas.
  4. Crie um Realtime Database e copie a URL.
  5. Nas regras, exija autenticação. Exemplo inicial:
{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null"
  }
}

A regra acima permite que todo usuário autenticado no projeto leia e altere os dados. Para uso real, limite permissões por usuário ou função. A configuração Web não substitui regras de segurança. A conexão depende de internet.
